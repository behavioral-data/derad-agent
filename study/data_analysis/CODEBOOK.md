# Codebook

Generated by `study.analysis.export_share`. Question text is taken from
the Qualtrics exports, so it is what participants actually saw.

## Identifiers and design

| column | meaning |
| --- | --- |
| `pid` | pseudonymised participant (`P0001`…). Not the Prolific ID. |
| `day` | session day, 1–3 |
| `position` | position of the post within that day's 12, 1–12. The Loop & Merge was static and unrandomised, so this is also the order seen |
| `condition_served` | which correction this participant saw, resolved from the opaque code the survey carried: `control` (the real Community Note), `neutral`, `agreeable`, `satirical` (AI replies) |
| `condition_assigned` | the arm recorded in the allocation table. Agrees with `condition_served` on all 14,172 trials |
| `party` | party from the Prolific pre-screen (`D`/`R`), which drove the party-adaptive question wording |
| `code` | the opaque per-(post, condition) token the survey carried |
| `post_id` | X post identifier |

## Post attributes (constant within a post)

| column | meaning |
| --- | --- |
| `topic` | one of six stratification topics |
| `polarity_condition` | stratum: `negative` / `center` / `positive` |
| `post_lean` | `right` / `left` / `contested-by-neither`. **`negative` polarity is a right-leaning post**, established by reading the ten posts at each pole and corroborated by the Community Notes rater-group columns |
| `polarity_score` | the note's position on the Community Notes rater-disagreement axis (`noteFactor_fn`). Measures **which partisan camp found the correction helpful**, not the post's lean directly |
| `polarity_abs` | absolute value of the above |
| `stance_polarity` | the viewpoint pipeline's stance-based polarity, correlates 0.78 with `polarity_score` |

## Ratings (one row per post)

Each item appears twice: the Qualtrics label, and `_n` for the numeric coding. **All scales are five-point**, coded 1–5 low to high.

| column | question as shown |
| --- | --- |
| `rate_enjoy`, `rate_enjoy_n` | Rate your agreement with the following statement: I enjoyed reading the response to this post. |
| `rate_inform`, `rate_inform_n` | Rate your agreement with the following statement: The response to this post was informative. |
| `rate_satisfied`, `rate_satisfied_n` | Rate your agreement with the following statement: I was satisfied with the quality of response to this post. |

Agreement scale: 1 strongly disagree, 2 somewhat disagree, 3 neither, 4 somewhat agree, 5 strongly agree.

## Behavioural measures from the interface

| column | meaning |
| --- | --- |
| `dwell_ms` | how long the post page was open |
| `note_visible_ms` | how long the correction itself was in the viewport. **Not comparable across arms** — control notes average 362 characters against 846–890 for the AI replies, so this is confounded with length |
| `gate_timeout` | the Next control was released by the 60-second fallback rather than by the response scrolling into view |
| `note_missing` | the correction failed to render. False on every row |
| `viewed_at` | timestamp of the exposure record |
| `blank_frame` | **no exposure record exists**: the frame never loaded and the participant rated a blank panel. 305 trials. Drop these ratings |
| `dwell_overwritten` | the timings on this row were overwritten by a Qualtrics validation redisplay, so they describe the second visit, not the whole view. 692 trials. **Ratings are unaffected**; timings are not usable. One participant recorded 54s across twelve posts while spending 31 minutes |
| `q_first_click`, `q_last_click`, `q_page_submit`, `q_click_count` | Qualtrics page timing. `q_page_submit` covers the whole page and is not affected by the redisplay problem, so prefer it for time-on-task |

## Bookkeeping

| column | meaning |
| --- | --- |
| `part1_status` … `part3_status` | Prolific submission status per part |
| `part1_minutes` … | time taken per part, minutes |
| `completed_all_parts` | approved on all three |
| `posts_day1` … `posts_day3` | posts with an exposure record that day |
| `blank_frames` | trials where the frame never loaded |
| `sessions_lost` | whole sessions with no exposure record at all |
| `pre_party_label`, `pre_outparty_label` | the party names piped into that participant's question wording |
